# Examples

These examples are intentionally documentation-first. They show how to adapt the
starter without turning this repository into a second application framework.

| Example | Use When |
| --- | --- |
| `cloudflare-supabase-crud` | You want a small API + table + RLS flow. |
| `ai-assistant` | You want an AI-worker shape with explicit capability gates. |

Each example keeps the same rule: one spec owner, one proof path, one cleanup
policy.
