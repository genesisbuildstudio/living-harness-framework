Living Harness Framework

A production-oriented monorepo starter that gives AI coding agents laws, source-of-truth docs, executable proof gates, and cleanup rules before your app grows into a maze.

GitHub Template Read First Release Proof 
pnpm create living-harness my-app --name "My App"

First Ten Minutes

cd my-app
pnpm install
pnpm lhf:onboard --name "My App" --slug "my-app" --platform codex --cloudflare --supabase --write
pnpm lhf:doctor
pnpm lhf:session-close --changed --check

What It Gives You

Agent Contract
Shared instructions for Codex, Claude Code, Copilot, and Cursor.
Truth Graph
Generated source/spec/proof map for AI-safe repo changes.
Proof Gates
Executable FST, session close, impact, and ticket checks.
Cloudflare + Supabase
Worker, RLS, pgTAP-style tests, and config hardening.
Public Release
Trusted-publishing workflow, immutable release checks, and install proof.
Maintenance
Dependabot, CodeQL, branch protection, support policy, and security reporting.
Benchmarking
Local harness score, agent conformance score, and receipt-backed proof.
Upgrades
Diff, apply, backup, and rollback for framework-owned files.
