# Support

Use the public issue templates for reproducible bugs and framework improvement
requests.

## Before Opening An Issue

Run the relevant proof command first:

```bash
pnpm lhf:session-close --changed --check
pnpm lhf:fst --task all
```

Include the command output, operating system, Node version, package manager, and
the exact AI coding platform involved.

## Security

Do not report vulnerabilities in public issues. Use GitHub private vulnerability
reporting when available, or email `security@genesis.build`.
