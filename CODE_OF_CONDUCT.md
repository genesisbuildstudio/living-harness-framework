# Code of Conduct

Living Harness Framework is for people building reliable AI-assisted software.
Contributions must stay practical, respectful, evidence-backed, and focused on
improving the framework.

## Expected Behavior

- Be direct without being hostile.
- Provide reproduction steps, proof output, and concrete alternatives.
- Respect security disclosure boundaries.
- Avoid spam, harassment, personal attacks, and low-signal promotion.

## Enforcement

Maintainers may edit, close, or remove issues, pull requests, comments, or
accounts that make the project less safe or less useful for builders.

Security issues belong in the private reporting path described in `SECURITY.md`.
